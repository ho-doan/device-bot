# QC web/LAN — kiểm thử còn lại

- Cập nhật: 2026-11-13, release v0.1.13.
## Windows/LAN cần kiểm thử tiếp

- Cài release trên Windows, mở `/qc/` từ browser của máy thứ hai; nhập token, Start/Open URL, input, Import YAML/Run, Review/Delete/Export.
- Xác minh video WebRTC và keyboard từ máy thứ hai; HTTPS vẫn cần cho các API capture bắt buộc secure context.
- Report LAN chỉ đọc; tạo project/import chỉ localhost. Không nhúng token vào bundle hoặc mở ra Internet.
