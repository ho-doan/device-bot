# QC Web và truy cập LAN

- Ngày: 2026-11-12. Cập nhật: **2026-11-12 — bind LAN, CORS, cùng origin `/qc` `/reports`, MCP client cho browser**.

## Mục tiêu

- Cả QC và robot-report phục vụ qua web ở IP LAN; máy khác trong mạng mở trình duyệt.
- Backend native và thiết bị nằm trên máy chủ; trình duyệt chỉ gọi API cùng origin.
- Không mở ra Internet. Ghi report (thêm project/import) vẫn chỉ localhost.

## Đã triển khai

1. MCP HTTP mặc định listen `0.0.0.0:<port>`; QC probe/discovery vẫn dùng `127.0.0.1`.
2. `device-bot start` bind robot-report `0.0.0.0`; probe health trên loopback.
3. Cùng origin: MCP phục vụ Flutter web tại `/qc/` (khi có `build/web` hoặc `DEVICE_BOT_QC_WEB_DIR`) và nest robot-report tại `/reports/`. `report.js`/`index.html` dùng đường dẫn tương đối + prefix `/reports`.
4. CORS: OPTIONS không cần bearer; origin allowlist là localhost và IP private; expose `mcp-session-id`; cho phép `Authorization`.
5. QC Flutter: `package:http` thay `dart:io HttpClient`; `local_connection` / recording filesystem tách stub cho web; URL mặc định trên web là `Uri.base.origin`; ô Bearer token khi chạy web. Không nhúng token vào bundle.
6. Auth LAN: bearer bắt buộc như trước. Remote không đọc file connection local.

## Còn hạn chế

- Cần `flutter build web --base-href /qc/` (hoặc rewrite `<base href>`) rồi đặt asset cạnh binary / `DEVICE_BOT_QC_WEB_DIR`.
- WebRTC/video, keyboard, YAML import trong browser cần xác minh từ máy thứ hai. HTTPS vẫn cần cho secure context ngoài HTTP LAN.
- Cây AX QC và drag/swipe macOS không thuộc phạm vi LAN.
