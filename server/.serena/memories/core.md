Rust workspace for Device Bot. Public boundaries: `mcp-protocol` owns JSON-RPC/MCP wire types; `mcp-server` owns stdio lifecycle and tool routing; `robot-core` owns platform-neutral Robot trait/registry; platform crates own device command integration. Keep tool-family modules and platform driver state separate to avoid a god file. Read `mem:tech_stack`, `mem:conventions`, `mem:task_completion` for concrete conventions.
